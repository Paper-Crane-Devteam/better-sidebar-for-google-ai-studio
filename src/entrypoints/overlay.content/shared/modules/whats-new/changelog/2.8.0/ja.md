## ✂️ とっておきの新機能：Snippets

Gemini と50往復チャットしたけど、本当に残したかったのはあの一段落、あのコードブロックだけ——そんな経験ありませんか？
**Snippets** はまさにそのための機能です。AI の回答から好きな部分を切り出して、専用の Snippet ライブラリに保存できます。フォルダ管理も付いているので、ふと浮かんだアイデアを二度と見失いません。（もちろん Snippet も Powerpack 経由で Notion・Obsidian にエクスポート可能です！）


## 📚 ヌルヌル動く、生まれ変わったサイドバー

この6週間で、サイドバー UI をゼロから作り直しました。よりクリーンで整理されていて、何より**アニメーションのカクつきを大幅に削減**。驚くほどスムーズになりました。

細かい使い勝手の改善もたくさん：
*   **👀 会話アウトライン：** チャットが長すぎて迷子？アウトラインビューを開けば、会話の構造が一目瞭然。
*   **📝 チャットメモ：** 個別のチャットにカスタムメモ/説明を追加できるようになりました。
*   **✨ リッチツールチップ：** サイドバーのチャットにホバーすると、作成日・メモ・タグが美しいツールチップで表示されます。
*   **📌 フォルダ強化：** お気に入りフォルダを**ピン留め**して先頭に固定！**ドラッグ＆ドロップ**で並べ替え、右クリックの「移動先...」オプションも追加。整理がこんなに楽だったことはありません。
*   **🎯 「アクティブチャットを検索」：** 深いフォルダ構造で現在地を見失った？検索ボタンをクリックするだけで、ツリーが自動展開して今のチャットまでスクロールします。

## ⚡ ワークフロー高速化

*   **Gem / Notebook のデフォルトフォルダ：** Gem や Notebook をよく使う方へ。それぞれにデフォルトフォルダを設定すれば、新しいチャットが自動で正しいフォルダに入ります。手動仕分け不要！
*   **スラッシュ `/` コマンド：** Gemini の入力欄で `/` を打つだけで、プロンプトライブラリを即座に呼び出せます。作業速度が格段にアップ。
*   **一括エクスポート：** バックアップが必要？複数の会話を選択して一度にエクスポートできます。
