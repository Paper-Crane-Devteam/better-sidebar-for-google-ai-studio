# 🔧 v2.8.1 — バグ修正と改善

v2.8.0 のクイックパッチアップデートです。

## 🐛 修正

*   **Notion API 権限がオプションに：** `api.notion` 権限がデフォルトでは不要になりました。Notion エクスポート機能を有効にした場合のみ、権限が要求されます。
*   **Snippet 詳細ページの修正：** Snippet 詳細ページで異なるタブを切り替えた際の表示ロジックの問題を修正し、z-index のレイヤー問題を解消しました。
*   **共有チャンネルの追加：** コンテンツ共有をより簡単にするための新しい共有チャンネルオプションを追加しました。

## 🎨 改善

*   **Library タブのスタイル調整：** Library タブの視覚的な細部を調整し、より統一感のある外観にしました。
