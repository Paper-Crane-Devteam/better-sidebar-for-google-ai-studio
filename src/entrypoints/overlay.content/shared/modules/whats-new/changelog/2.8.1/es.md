# 🔧 v2.8.1 — Correcciones y mejoras

Un parche rápido para solucionar algunos problemas de la versión v2.8.0.

## 🐛 Correcciones

*   **El permiso de Notion API ahora es opcional:** El permiso `api.notion` ya no es obligatorio por defecto. Solo se solicitará cuando actives la función de exportación a Notion.
*   **Corrección en la página de detalle de Snippet:** Se corrigió la lógica de visualización al cambiar entre pestañas en la página de detalle de Snippet, y se solucionaron los problemas de z-index.
*   **Canal de compartir añadido:** Se añadió una nueva opción de canal para compartir contenido de forma más sencilla.

## 🎨 Mejoras

*   **Ajustes de estilo en la pestaña Library:** Refinamientos visuales menores en la pestaña Library para una apariencia más consistente.
