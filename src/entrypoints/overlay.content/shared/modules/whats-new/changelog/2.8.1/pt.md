# 🔧 v2.8.1 — Correções e melhorias

Uma atualização rápida para corrigir alguns problemas da versão v2.8.0.

## 🐛 Correções

*   **Permissão da API do Notion agora é opcional:** A permissão `api.notion` não é mais obrigatória por padrão. Ela só será solicitada quando você ativar a função de exportação para o Notion.
*   **Correção na página de detalhes do Snippet:** Corrigida a lógica de exibição ao alternar entre abas na página de detalhes do Snippet, e corrigidos os problemas de z-index.
*   **Canal de compartilhamento adicionado:** Adicionada uma nova opção de canal para facilitar o compartilhamento de conteúdo.

## 🎨 Melhorias

*   **Ajustes de estilo na aba Library:** Refinamentos visuais menores na aba Library para uma aparência mais consistente.
