# 🔧 v2.8.1 — Bug 修復與改進

針對 v2.8.0 的一次快速修補更新。

## 🐛 修復

*   **Notion API 權限改為可選：** `api.notion` 權限不再預設要求，只有當你實際啟用 Notion 匯出功能時才會請求授權。
*   **Snippet 詳情頁修復：** 修復了在 Snippet 詳情頁中切換不同 Tab 時的顯示邏輯問題，並修正了層級關係（z-index）異常。
*   **新增分享管道：** 添加了新的分享管道選項，方便內容分享。

## 🎨 優化

*   **Library 標籤頁樣式優化：** 對 Library 標籤頁進行了視覺細節調整，整體觀感更加統一。
