# 🔧 v2.8.1 — Bug 修复与改进

针对 v2.8.0 的一次快速修补更新。

## 🐛 修复

*   **Notion API 权限改为可选：** `api.notion` 权限不再默认要求，只有当你实际启用 Notion 导出功能时才会请求授权。
*   **Snippet 详情页修复：** 修复了在 Snippet 详情页中切换不同 Tab 时的显示逻辑问题，并修正了层级关系（z-index）异常。
*   **新增分享渠道：** 添加了新的分享渠道选项，方便内容分享。

## 🎨 优化

*   **Library 标签页样式优化：** 对 Library 标签页进行了视觉细节调整，整体观感更加统一。
