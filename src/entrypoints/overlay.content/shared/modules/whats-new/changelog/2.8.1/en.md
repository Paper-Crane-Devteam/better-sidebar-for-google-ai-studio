# 🔧 v2.8.1 — Bug Fixes & Improvements

A quick patch to iron out a few issues from the v2.8.0 release.

## 🐛 Fixes

*   **Notion API permission is now optional:** The `api.notion` permission is no longer required by default. It will only be requested when you actually enable the Notion export feature.
*   **Snippet detail view fixes:** Fixed display logic when switching between different tabs in the Snippet detail page, and corrected the z-index layering issues.
*   **Share channel added:** Added a new sharing channel option for easier content sharing.

## 🎨 Improvements

*   **Library tab styling polish:** Minor visual refinements to the Library tab for a more consistent look and feel.
