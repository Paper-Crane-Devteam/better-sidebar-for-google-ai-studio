# 🔧 v2.8.1 — Исправления и улучшения

Быстрый патч для устранения нескольких проблем из версии v2.8.0.

## 🐛 Исправления

*   **Разрешение Notion API теперь необязательно:** Разрешение `api.notion` больше не требуется по умолчанию. Оно будет запрашиваться только при включении функции экспорта в Notion.
*   **Исправлена страница деталей Snippet:** Исправлена логика отображения при переключении между вкладками на странице деталей Snippet, а также устранены проблемы с z-index.
*   **Добавлен канал для обмена:** Добавлена новая опция канала для удобного обмена контентом.

## 🎨 Улучшения

*   **Улучшен стиль вкладки Library:** Внесены визуальные доработки вкладки Library для более единообразного внешнего вида.
