# ✨ v2.9.1 — 預設資料夾與劃詞工具列

2.9.0 之後的一個小版本，內容幾乎全部來自你們的回饋。感謝每一條回饋。🙏

## ✨ 新增

*   **📁 Gem 與 Notebook 預設資料夾：** 可以為任意 Gem 或 Notebook 指定一個預設資料夾。從它建立新對話時，對話會自動進入那個資料夾，不用事後再拖一次。
*   **🖍️ 劃詞工具列：** 在對話裡選取任意文字，上方會出現一個小工具列。可以讓 AI 解釋或摘要選取的內容，也可以存成 Snippet 或直接複製。可在設定裡調整——自己挑要顯示哪些操作，或者整個關掉。

## 🐛 修復

*   **⚪ 舊對話裡的灰點，終於能清了。** v2.9.0 讓新對話不再留下失效的灰點，但已有的對話還是留著。當時沒做清理腳本，是怕誤傷大家的歷史記錄。現在是安全版本：當一個對話裡存在殘留記錄時，Smart Scrollbar 頂部會出現一個清理按鈕。點一次待確認，再點一次執行，就這麼簡單。它只會刪除這個對話本身已經不再引用的記錄，不會碰任何尚未核實過的歷史，一旦發現資料對不上就完全不動手。
*   **⋯ Gemini 原生三點選單位置錯亂。** 你說得對，這個確實是我的問題——擴充功能的部分 CSS 影響到了 Google 自己的操作選單，把它的位置擠歪了。已修復。
*   **📂 資料夾操作按鈕和長名稱糊在一起。** 以前資料夾名稱太長時，文字會從懸浮按鈕下面透出來，看起來一團亂。現在名稱會在按鈕後面乾淨地截斷。
*   **📝 Snippet 遺失 Markdown 格式。** 儲存 Snippet 時文字留下了，格式卻掉了。已經定位並修復——標題、清單、程式碼區塊這些現在都能完整保留。
