# ✨ v2.9.1 — 預設資料夾與劃詞工具列

這是一次基於大家回饋的快速迭代版本。感謝每一位用戶的建議與回饋。🙏

## ✨ 新增功能

*   **📁 Gem 與 Notebook 預設資料夾：** 現在可以為任意 Gem 或 Notebook 指定一個預設資料夾。當你從這些預設建立對話時，對話將自動歸入指定的資料夾，無需再手動移動。
*   **⚡ 在資料夾端管理預設關聯：** 資料夾設定面板中現在會列出所有將其設為「預設資料夾」的 Gem 和 Notebook，你可以在這裡直接綁定或解除綁定。此外，當一個資料夾被設為預設資料夾時，它的懸浮操作列會增加一個快捷按鈕，方便你一鍵新建相關的對話。
*   **🗑️ 可選：跳過刪除確認：** 此功能預設關閉。在「設定 → 一般」中開啟後，刪除單個對話時將跳過確認提示直接執行。請注意：此操作立即生效、永久刪除且無法撤銷，將同時刪除擴充功能與平台上的資料。批次刪除操作仍會進行確認提示。
*   **🖍️ 劃詞工具列：** 在對話中選取文字時，上方會顯示一個小巧的快捷工具列。你可以讓 AI 解釋或總結選取的內容，也可以將其儲存為 Snippet 或直接複製。你可以在設定中自訂需要顯示的操作項，或完全關閉此功能。

## 🐛 問題修復

*   **⚪ 清理歷史對話中的無效灰點：** 在 v2.9.0 中，我們優化了新對話的渲染，不再產生失效的記錄灰點。為了保障歷史資料的絕對安全，現在我們提供了一個安全的清理方式：當對話中存在殘留記錄時，Smart Scrollbar 頂部會出現一個清理按鈕。點擊並確認後，系統只會刪除不再被引用的無效記錄，不會影響任何正常的歷史資料。若檢測到資料異常，清理操作將自動終止。
*   **⋯ 修復 Gemini 原生選單位置偏移：** 修復了因擴充功能 CSS 樣式衝突，導致 Gemini 原生的「更多操作」選單位置顯示錯亂的問題。
*   **📂 修復資料夾名稱過長時的顯示問題：** 修復了當資料夾名稱過長時，文字與懸浮操作按鈕重疊的問題。現在超長的名稱會被正確截斷隱藏。
*   **📝 修復 Snippet 遺失 Markdown 格式：** 修復了在儲存 Snippet 時文字格式遺失的問題。現在，包括標題、列表、程式碼區塊在內的所有 Markdown 格式均能被完整保留。
