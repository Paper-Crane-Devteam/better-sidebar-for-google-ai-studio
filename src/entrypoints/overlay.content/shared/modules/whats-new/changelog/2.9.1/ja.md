# ✨ v2.9.1 — デフォルトフォルダと選択ツールバー

2.9.0 に続く小さなアップデートで、内容のほぼすべてが皆さんのフィードバックから生まれました。ご報告ありがとうございます。🙏

## ✨ 新機能

*   **📁 Gem と Notebook のデフォルトフォルダ：** 任意の Gem または Notebook にデフォルトフォルダを設定できます。そこから新しいチャットを始めると、会話が自動的にそのフォルダに入ります。後からドラッグする必要はありません。
*   **🖍️ テキスト選択ツールバー：** 会話内のテキストを選択すると、そのすぐ上に小さなツールバーが表示されます。選択部分の説明や要約を AI に依頼したり、スニペットとして保存したり、コピーしたりできます。設定から調整可能です。表示するアクションを選ぶことも、機能全体をオフにすることもできます。

## 🐛 修正

*   **⚪ 古い会話のグレーのドットを削除できるようになりました。** v2.9.0 で新しいチャットが無効なドットを残さなくなりましたが、既存のスレッドには残ったままでした。皆さんの履歴を壊すリスクを避けたかったため、クリーンアップ処理は見送っていました。今回は安全な形で実装しました。会話に残留レコードがある場合、Smart Scrollbar の上部にクリーンアップボタンが表示されます。1 回目のクリックで確認待ち、2 回目で実行されます。削除されるのは、その会話自身がすでに参照していないレコードのみです。未検証の履歴には一切触れず、データに不整合があれば何も実行しません。
*   **⋯ Gemini ネイティブの 3 点メニューの位置ずれ。** ご指摘のとおり、これは私の側の問題でした。拡張機能の CSS の一部が Google 自身のアクションメニューに影響し、位置をずらしていました。修正済みです。
*   **📂 フォルダ操作ボタンと長い名前が重なる問題。** フォルダ名が長いとき、テキストがホバーボタンの下から透けて見えて読みにくくなっていました。名前はボタンの後ろできれいに省略表示されるようになりました。
*   **📝 スニペットの Markdown 書式が失われる問題。** スニペットを保存するとテキストは残るものの書式が抜け落ちていました。原因を特定して修正済みです。見出し、リスト、コードブロックなどがそのまま保持されます。
