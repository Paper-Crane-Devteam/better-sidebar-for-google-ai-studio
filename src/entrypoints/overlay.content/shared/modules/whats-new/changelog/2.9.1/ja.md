# ✨ v2.9.1 — デフォルトフォルダと選択ツールバー

これは皆様のフィードバックに直接基づいた迅速なイテレーションリリースです。ご提案をいただいたすべての皆様に感謝いたします。🙏

## ✨ 新機能

*   **📁 Gem および Notebook のデフォルトフォルダ：** 任意の Gem または Notebook にデフォルトのフォルダを割り当てることができるようになりました。そのプリセットを使用して新しい会話を開始すると、自動的に指定されたフォルダに配置されるため、後で手動で移動する手間が省けます。
*   **⚡ フォルダ側からのデフォルト関連付けの管理：** フォルダ設定パネルに、そのフォルダをデフォルトとして使用しているすべての Gem および Notebook が一覧表示されるようになり、直接バインドまたはバインド解除できるようになりました。さらに、フォルダがデフォルトとして設定されている場合、ホバーアクションバーにショートカットボタンが追加され、ワンクリックで関連する会話を作成できます。
*   **🗑️ オプション：削除確認をスキップ：** この機能はデフォルトで無効になっています。「設定 → 一般」で有効にすると、単一の会話を削除する際に確認ダイアログがスキップされます。注意：この操作は即時に実行され、取り消すことはできず、拡張機能とクラウドプラットフォームの両方からデータが完全に削除されます。一括削除の場合は、引き続き確認が求められます。
*   **🖍️ テキスト選択ツールバー：** 会話内のテキストを選択すると、その上にコンパクトなツールバーが表示されます。AI に選択範囲を説明または要約させたり、スニペットとして保存したり、単にコピーしたりできます。設定で表示するアクションをカスタマイズしたり、ツールバーを完全に無効にしたりできます。

## 🐛 バグ修正

*   **⚪ 過去のチャットの無効な灰色のドットをクリーンアップ：** v2.9.0 では、新しい会話のレンダリングを最適化し、無効な記録ドットが残らないようにしました。過去のデータの安全性を完全に確保するために、安全なクリーンアップ方法を提供します。会話に残留記録が存在する場合、スマートスクロールバーの上部にクリーンアップボタンが表示されます。クリックして確認すると、システムは参照されていない無効な記録のみを削除し、通常の履歴には影響しません。データ異常が検出された場合、クリーンアップ操作は自動的に中止されます。
*   **⋯ Gemini ネイティブメニューのずれを修正：** 拡張機能の CSS の競合により、Google のネイティブの「その他の操作」メニューの位置がずれて表示される問題を修正しました。
*   **📂 長いフォルダ名の表示問題を修正：** 長いフォルダ名がホバーアクションボタンと重なる問題を修正しました。長すぎる名前は適切に切り捨てられ、非表示になるようになりました。
*   **📝 スニペットにおける Markdown フォーマットの消失を修正：** スニペットを保存する際にテキストのフォーマットが失われる問題を修正しました。見出し、リスト、コードブロックなど、すべての Markdown フォーマットが完全に保持されるようになりました。
