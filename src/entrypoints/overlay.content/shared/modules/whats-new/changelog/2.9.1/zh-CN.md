# ✨ v2.9.1 — 默认文件夹与划词工具栏

2.9.0 之后的一个小版本，内容几乎全部来自你们的反馈。感谢每一条反馈。🙏

## ✨ 新增

*   **📁 Gem 与 Notebook 默认文件夹：** 可以给任意 Gem 或 Notebook 指定一个默认文件夹。从它新建对话时，对话会自动进入那个文件夹，不用事后再拖一次。
*   **🖍️ 划词工具栏：** 在对话里选中任意文字，上方会出现一个小工具栏。可以让 AI 解释或总结选中内容，也可以存为 Snippet 或直接复制。可在设置里配置——自己挑要显示哪些操作，或者整个关掉。

## 🐛 修复

*   **⚪ 老对话里的灰点，终于能清了。** v2.9.0 让新对话不再留下失效的灰点，但已有的对话还是留着。当时没做清理脚本，是怕误伤大家的历史记录。现在是安全版本：当一个对话里存在残留记录时，Smart Scrollbar 顶部会出现一个清理按钮。点一次待确认，再点一次执行，就这么简单。它只会删除这个对话本身已经不再引用的记录，不会碰任何尚未核实过的历史，一旦发现数据对不上就完全不动手。
*   **⋯ Gemini 原生三点菜单位置错乱。** 你说得对，这个确实是我的问题——插件的部分 CSS 影响到了 Google 自己的操作菜单，把它的位置挤歪了。已修复。
*   **📂 文件夹操作按钮和长名字糊在一起。** 以前文件夹名字太长时，文字会从悬浮按钮下面透出来，看着一团乱。现在名字会在按钮后面干净地截断。
*   **📝 Snippet 丢失 Markdown 格式。** 保存 Snippet 时文字留下了，格式却掉了。已经定位并修复——标题、列表、代码块这些现在都能完整保留。
