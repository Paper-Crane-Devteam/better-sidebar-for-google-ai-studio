# ✨ v2.9.1 — 默认文件夹与划词工具栏

这是一次基于大家反馈的快速迭代版本。感谢每一位用户的建议与反馈。🙏

## ✨ 新增功能

*   **📁 Gem 与 Notebook 默认文件夹：** 现在可以为任意 Gem 或 Notebook 指定一个默认文件夹。当你从这些预设新建对话时，对话将自动归入指定的文件夹，无需再手动移动。
*   **⚡ 在文件夹端管理默认关联：** 文件夹设置面板中现在会列出所有将其设为“默认文件夹”的 Gem 和 Notebook，你可以在这里直接绑定或解除绑定。此外，当一个文件夹被设为默认文件夹时，它的悬浮操作栏会增加一个快捷按钮，方便你一键新建相关的对话。
*   **🗑️ 可选：跳过删除确认：** 此功能默认关闭。在「设置 → 通用」中开启后，删除单个对话时将跳过确认提示直接执行。请注意：此操作立即生效、永久删除且无法撤销，将同时删除插件与平台上的数据。批量删除操作仍会进行确认提示。
*   **🖍️ 划词工具栏：** 在对话中选中文本时，上方会显示一个小巧的快捷工具栏。你可以让 AI 解释或总结选中的内容，也可以将其保存为 Snippet 或直接复制。你可以在设置中自定义需要显示的操作项，或完全关闭此功能。

## 🐛 问题修复

*   **⚪ 清理历史对话中的无效灰点：** 在 v2.9.0 中，我们优化了新对话的渲染，不再产生失效的记录灰点。为了保障历史数据的绝对安全，现在我们提供了一个安全的清理方式：当对话中存在残留记录时，Smart Scrollbar 顶部会出现一个清理按钮。点击并确认后，系统只会删除不再被引用的无效记录，不会影响任何正常的历史数据。若检测到数据异常，清理操作将自动终止。
*   **⋯ 修复 Gemini 原生菜单位置偏移：** 修复了因插件 CSS 样式冲突，导致 Gemini 原生的“更多操作”菜单位置显示错乱的问题。
*   **📂 修复文件夹名称过长时的显示问题：** 修复了当文件夹名称过长时，文字与悬浮操作按钮重叠的问题。现在超长的名称会被正确截断隐藏。
*   **📝 修复 Snippet 丢失 Markdown 格式：** 修复了在保存 Snippet 时文本格式丢失的问题。现在，包括标题、列表、代码块在内的所有 Markdown 格式均能被完整保留。
