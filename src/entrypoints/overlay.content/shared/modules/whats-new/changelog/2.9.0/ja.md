# 🤖 v2.9.0 — Agent、着陸

v2.8.0 で言ったの覚えてます？*「Agent はまだオーブンの中。」* はい、タイマー鳴りました。🔔

2ヶ月半。コーヒー何杯飲んだかわからない。エンジンは何回書き直したか公の場では言いたくない。**AI Agent、正式リリースです。**

まず一番大事なことを言わせてください。他のサイドバー拡張機能が提供するのは「ボタン」——押すと1つのことが起きる。こっちが提供するのは**作業員**。やりたいことを自然な言葉で伝えると、AI が実際にやってくれる——データを読んで、判断して、マルチステップで実行して、終わったら報告してくる。全部あなた自身のブラウザ内で、あなた自身の Gemini セッションを使って。API キー不要、追加トークン消費なし、データはマシンの外に一切出ない。

## 🚀 目玉：AI Agent

Gemini の入力ボックスで `>` を打つ。以上。これがインターフェースの全部。

リストが出る。**スキル**を選んでもいいし、最初の項目を選んで AI に任せてもいい。あとは「仕事を頼む」感覚でやりたいことを書くだけ。

**最初から使えるスキル：**

*   **🗂️ 自動整理：** 「最近200件のチャットをフォルダに分けてタグも付けて。」タイトルを読んで、分類体系を考えて、フォルダ作って、全部移動する。半年分の未整理カオスを一発で片付ける。
*   **🔄 検索インデックスの補完：** 知ってました？会話のメッセージ内容は、あなたがそのチャットを開いた時にだけ記録される。拡張機能をインストールする前の古いチャットは、データベース上タイトルだけで中身が空——全文検索でヒットしない本当の理由がこれ。このスキルは空の会話を見つけてメッセージを同期してくれる。一度やってまだ空なら？Google 側にもう存在しないゴースト。Agent に消してもらえばOK。
*   **📊 自分のデータに質問する：** 会話履歴をデータベースとして質問できる——実際そうだから。「先月一番チャットが多いフォルダはどれ？」聞けば答えてくれる。
*   **📝 Prompt・Snippet を一括管理：** 書き直し、再分類、重複削除、再構成——散らかった山を使える図書館にする。
*   **🛠️ 自分でスキルを書く：** **設定 → Agent** で、自分の指示を使ってカスタムスキルを定義できる。繰り返しの作業フローを言葉にできるなら、Agent に教えられる。あとはワンクリックのカードになる。

### 🔓 ここまでが全部だと思わないで

上のスキルは**プリセットであって限界じゃない**。ここが一番伝えたいこと。

Agent は拡張機能のデータベースに直接クエリを投げられる——会話、メッセージ、フォルダ、タグ、Prompt、Snippet、全部。5つの決まった動作から選んでるわけじゃない。自分で SQL を書いてあなたのデータを調べて、結果を見て、次に何するか決める。だから本当の能力の境界は：**あなたのデータについて言葉にできることなら、だいたい何でもできる。**

上限を探すには：

*   `>` を打って**直接聞く**。「俺のデータで何ができるの？」「ここで散らかってるところ教えて？」どんなテーブルが見えるか、どんなツールがあるか本人が知ってるので、セールスさせればいい。
*   **検索ボックスじゃなくて人間相手として話す。** マルチターン対話に対応してて、コンテキストは繋がってる。「面白い、月別に分解して。」「スター付きのも同じようにやって。」「やっぱあの2フォルダ統合して。」どんどん追加で指示を出せる。
*   俺が機能として設計し切れないことを聞く：「何度も同じ話題に戻ってるのどれ？」「3月のauthバグ関連のチャット集めて1フォルダに。」「一度も使ってないPromptどれ？」「先四半期何やってたかまとめて。」

正直、一番カッコいい使い方は俺が想像もしてないやつだと思う。触ってみて、何が起きたか教えてください。

**安全面、ちゃんとやってます：**

*   **🛑 あなたが常に最終判断。** 書き込み操作は必ず許可を求める。読み取りはフリー。ポリシーはあなたが決めて、セッション単位で変更可能。
*   **⚡ スピードモード** 信頼するならONにすれば質問しなくなる。（取り消しあり、安心して。）
*   **🎛️ Agent Dock** が入力ボックスの上に常駐——サイドバー閉じても消えない。ステータス、停止ボタン、承認、全部ここ。「まだ動いてんの？」はもうない。
*   **🔌 サーキットブレーカーだらけ。** ループ、繰り返し、進捗なし→エンジンが自動で止めて理由を教えてくれる。長時間放置されてたら自分から確認してくる、裏で延々回り続けたりしない。

**💚 早期購入価格で Powerpack を買ってくれた方——この機能、今すぐ無料で使えます。** まだ存在してなかった時に信じてくれた。ありがとう。`>` を打ってみて。

## ✨ ついでにこれも

*   **⚡ Gemini Spark 統合：** Google があなたのアカウントに Spark を展開してれば、サイドバーにタブが自動で出る。設定不要——あれば出る。
*   **🎨 UIがスッキリした：** 全体的にノイズを下げた。スペーシング、コントラスト、テーマ全部調整済み。ゴチャゴチャ感が減った。あと**テーマ切替時にアニメーション遷移**が入った。小さいけど気持ちいい。
*   **🎛️ 拡張機能アイコンクリックで設定パネル：** ツールバーのアイコンが本物のコントロールパネルを開くようになった。プラットフォームや機能のON/OFFがメニューなしで。
*   **⌨️ AI Studio でも `/` 対応：** `/` で Prompt ライブラリを呼び出すショートカット、Gemini だけだったのが AI Studio でも使えるように。
*   **💾 自動ローカルバックアップ：** 拡張機能のデータが定期的に自動バックアップされるようになった。手動スナップショットもいつでも可能。何かあっても前の状態に戻せる。安心感、やっと出荷。
*   **📜 Smart Scrollbar が展開可能に：** クリックでメッセージ一覧に展開。長い会話がやっとナビゲートできる。
*   **📁 移動ダイアログ内でフォルダ作成可能に：** 「フォルダに移動」ダイアログに**新規フォルダ**ボタン追加。小さいことだけど、なかったの地味にストレスだった。

## 🐛 バグ修正 — 1つ重要なやつがある

*   **☁️ Google Drive同期がデータを食わなくなった。** 正直に言います：以前の自動マージロジックはローカルデータを上書きすることがあった。**廃止しました。** Drive がローカルデータを勝手に上書き・マージすることは二度とない。復元するなら手動でダウンロードを発動する必要がある。アップロードは引き続き自動（同期ONの場合）。ローカルデータが唯一の真実、以上。
*   **🔍 Gemini の会話スキャン修正。** チャットリストのスキャンがまた安定して動くように。
*   **😴 「放置してたら死んでた」問題修正。** タブを数時間放置して戻ったらサイドバーがゾンビだった件、直した。再接続が正しく動く。
*   **📐 Gemini ページの謎の上方ジャンプ修正。** あの間欠的なレイアウトの飛びがなくなった。
*   **⌨️ スペースでリネームが終了しなくなった。** リネーム中にスペース打っても編集モードを抜けなくなった。
*   **🕒 タイムスタンプ修正。** 作成日時・最終アクティブ日時が正確に表示されるように。
*   **💎 Gem・Notebook が作成直後に検出されるように。** リロードの儀式が不要に。
*   **⚪ 灰色の死んだドットが消えた。** Smart Scrollbar でたまに出てたクリック不能ドット、修正。
