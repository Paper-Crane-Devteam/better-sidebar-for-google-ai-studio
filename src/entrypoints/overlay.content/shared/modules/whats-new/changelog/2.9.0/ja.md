# 🤖 v2.9.0 — AI Agent、正式リリース

一定の開発期間とアーキテクチャの調整を経て、新しい機能「**AI Agent**」をお届けします。🎉

私たちは、単なるショートカットボタンではなく、より実用的な**インテリジェントアシスタント**を提供したいと考えています。自然な言語で必要なことを伝えると、アシスタントがデータの検索、分析、段階的な実行を試み、完了後に報告してくれます。これらはすべてブラウザ内でローカルに実行され、現在の Gemini セッションを使用します。API キーは不要で、追加のトークンを消費することもありません。データがデバイスから離れることはなく、プライバシーは保護されます。

## 🚀 コアアップデート：AI Agent

Gemini の入力ボックスに `>` と入力して呼び出します。

リストがポップアップ表示され、**プリセットスキル**を選択するか、自然な言葉でリクエストを記述して AI に実行方法を判断させることができます。

**お試しいただけるよう、以下の基本的なスキルを用意しました：**

*   **🗂️ 自動整理：** 「過去 200 件の会話をフォルダに分類し、タグ付けして。」 タイトルを自動的に分析し、分類を試み、フォルダを作成し、移動を完了して、蓄積された会話の整理をサポートします。
*   **🔄 検索インデックスの補完：** 全文検索で古い会話が見つからないことがあることにお気づきかもしれません。これは、拡張機能をインストールする前の古いチャットでは、デフォルトでデータベースにタイトルしかないためです。このスキルは、それらの「空の」チャットを見つけ、コンテンツを自動的に同期します。同期後も空の場合は、クラウドからもデータが失われていることを意味し、Agent はこれらの無効なデータのクリーンアップをサポートします。
*   **📊 データクエリ：** 「先月、最も会話が多かったフォルダは？」 質問するだけで、ローカルデータを照会して回答を提供します。
*   **📝 プロンプトとスニペットの一括管理：** ライブラリの整理に役立つように、リライト、再分類、重複排除、または再編成をサポートします。
*   **🛠️ カスタムスキル：** **設定 → Agent** で、独自の指示を使用して新しいスキルを定義できます。繰り返しのワークフローがある場合は、Agent に教えておけば、次回からワンクリックで実行できます。

### 🔓 さらなる可能性を探る

プリセットスキルに加えて、Agent は会話、メッセージ、フォルダ、タグ、プロンプト、スニペットなど、拡張機能のデータベースを直接クエリできます。ニーズに基づいてクエリを自動的に記述し、結果を分析して、次の手順を決定できます。ローカルデータに関することであり、明確に記述できるものであれば、Agent に実行を依頼してみてください。

以下のような使い方をお試しいただけます。

*   `>` と入力して**直接聞いてみる**：「私のデータで何ができるの？」または「整理が必要なデータはある？」と尋ねて、提案を聞いてみましょう。
*   **マルチターン会話を通じてアシスタントと対話する。** コンテキストは維持されます。例：「面白いね。じゃあ月ごとに分解してみて。」「星付きのチャットにも同じルールを適用して。」「やっぱり、その 2 つのフォルダを統合して。」
*   プリセットを作成していないリクエストを試す：「私が一番よく話すトピックは何？」「3 月の auth バグに関する会話を見つけてグループ化して。」「一度も使ったことのないプロンプトはどれ？」
*   面白い使い道を見つけた場合は、ぜひ私たちと共有してください。

**セキュリティと制御について：**

*   **🛑 あなたが決める。** デフォルトでは、データを変更するアクションはすべて、最初にあなたの確認を求めますが、読み取り操作は直接実行できます。これらのポリシーは設定でいつでも調整できます。
*   **⚡ 最速モード。** その操作に精通しており、信頼できる場合は、最速モードを有効にして確認をスキップできます。（すべての操作は取り消し可能です。）
*   **🎛️ Agent Dock。** ステータスバーは入力ボックスの上に固定されているため、サイドバーが閉じていても、現在の進行状況を確認できます。ステータス、停止ボタン、承認は一目でわかります。
*   **🔌 スマートサーキットブレーカー。** Agent がループに陥ったり、進行が遅くなったりした場合、エンジンは自動的に中断し、理由を通知します。実行時間が長すぎる場合は、バックグラウンドで無限に実行されるのではなく、一時停止して入力を求めます。

## ✨ さらなる機能改善

*   **⚡ Gemini Spark 統合：** アカウントで Google Spark が有効になっている場合、サイドバーに Spark タブが自動的に表示されます。
*   **🎨 ビジュアルの更新：** インターフェース全体が再調整され、間隔がよりコンパクトになり、コントラストがより快適になりました。また、テーマ切り替え時のトランジションアニメーションを追加し、より良い視覚体験の提供を目指しています。
*   **🎛️ クイック設定へのアクセス：** ブラウザツールバーの拡張機能アイコンをクリックすると、コントロールパネルが開き、プラットフォームや機能のオン/オフをすばやく切り替えることができます。
*   **⌨️ AI Studio での `/` サポート：** プロンプトライブラリを呼び出す `/` ショートカットは以前は Gemini 専用でしたが、AI Studio でも使用できるようになりました。
*   **💾 自動ローカルバックアップ：** 拡張機能データは定期的な自動バックアップをサポートするようになり、いつでも手動でスナップショットを作成してデータの安全性を高めることができます。
*   **📜 スマートスクロールバーの強化：** スマートスクロールバーをクリックするとメッセージリストに展開され、長い会話の閲覧が容易になります。
*   **📁 新しいフォルダボタン：** 「フォルダに移動」モーダル内に、直接新しいフォルダを作成するボタンを追加しました。

## 🐛 バグ修正

*   **☁️ Google Drive 同期ロジック：** 以前の自動マージロジックを改善しました。Drive がローカルデータを自動的に上書きしたり、マージしたりすることはなくなりました。データを復元するには、手動でダウンロードを開始する必要があります。アップロードは引き続き自動で行われます（同期が有効な場合）。これにより、ローカルデータが常に最も信頼できるソースであることが保証されます。
*   **🔍 Gemini 会話スキャン：** 会話リストのスキャンが時折失敗する問題を修正しました。
*   **😴 スリープ切断の問題：** タブを長時間アイドル状態にした後、サイドバーが応答しなくなる問題を修正しました。正常に再接続できるようになりました。
*   **📐 ページのジャンプ：** Gemini インターフェースで時折発生するレイアウトの揺れを解決しました。
*   **⌨️ スペースキーでの名前変更の終了：** 名前変更時にスペースを入力しても、誤って編集モードが終了しなくなりました。
*   **🕒 時間表示エラー：** 会話の作成時間と最終アクティブ時間が正しく表示されるようになりました。
*   **💎 リアルタイムの Gem/Notebook 検出：** 新しい Gem または Notebook は、作成後すぐに拡張機能によって検出されるようになりました。
*   **⚪ 灰色のデッドピクセル：** スマートスクロールバーに時折表示される、クリックできないドットを修正しました。
