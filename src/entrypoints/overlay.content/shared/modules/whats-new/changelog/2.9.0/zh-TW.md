# 🤖 v2.9.0 —— AI Agent 正式上線

經過一段時間的開發與底層架構調整，我們為大家帶來了一個全新的功能：**AI Agent**。🎉

我們希望為你提供一個更實用的**智慧助手**，而不僅僅是幾個快捷按鈕。你可以用自然語言告訴它你的需求，它會嘗試主動檢索你的資料、進行分析判斷、分步驟執行，並在完成後向你彙報。所有這一切都在你的瀏覽器本機執行，使用的是你目前的 Gemini 會話，不需要 API key，不消耗額外 token，資料也絕對不會離開你的設備，確保隱私安全。

## 🚀 核心更新：AI Agent

在 Gemini 輸入框中輸入 `>` 即可喚出。

此時會彈出一個列表，你可以選擇一個**預設技能**，或者不選，直接用自然語言描述你的需求，讓 AI 自己判斷如何執行。

**我們準備了以下基礎技能供大家體驗：**

*   **🗂️ 自動整理：** 「幫我把最近 200 個對話分類到資料夾中，並打上標籤。」它會自動分析對話標題、嘗試進行分類、建立資料夾，並完成移動，協助你整理積壓的對話記錄。
*   **🔄 補全搜尋索引：** 你可能注意到，全文搜尋有時找不到一些早期的對話內容。這是因為在安裝擴充功能前的舊對話，資料庫中預設只有標題。這個技能可以幫你找出這些「空殼」對話，並自動同步內容。如果同步後依然為空，說明雲端也已失效，Agent 會協助你清理這些無效資料。
*   **📊 資料查詢：** 「上個月哪個資料夾裡的對話最多？」直接提問，它會查詢本機資料並給出答案。
*   **📝 批次管理 Prompt 和 Snippet：** 協助重寫、重新分類、去重或重新組織，幫助整理你的素材庫。
*   **🛠️ 自訂技能：** 在**設定 → Agent** 中，你可以用自己的指令來定義新技能。如果你有重複性的工作流程，可以嘗試教給它，之後只需一鍵即可運行。

### 🔓 探索更多可能

除了預設技能，Agent 底層支援直接查詢擴充功能的資料庫，包括對話、訊息、資料夾、標籤、Prompt 和 Snippet 等。它能夠根據你的需求自動編寫查詢語句，分析結果，並決定下一步操作。只要是與你本機資料相關的操作，只要能清晰描述，都可以嘗試讓它去完成。

你可以嘗試以下使用方式：

*   輸入 `>` 直接**問它**：「你能用我的資料做些什麼？」或「我的資料裡有哪些需要整理的地方？」聽聽它的建議。
*   **把它當成助手進行多輪對話。** 它支援上下文連貫。例如：「很有意思，請按月份再拆分看看。」「把標了星標的對話也按這個規則處理一下。」「算了，把那兩個資料夾合併吧。」 
*   嘗試一些我們沒有預設的功能：「我經常聊哪些話題？」「把三月份關於 auth bug 的對話找出來整理到一起。」「我有哪些 Prompt 從沒使用過？」 
*   如果你發現了有趣的用法，歡迎隨時分享給我們。

**在安全性與可控性方面：**

*   **🛑 你來決定。** 預設情況下，所有修改資料的操作都會先詢問你的確認，讀取操作則可以直接執行。你可以隨時在設定中調整策略。
*   **⚡ 極速模式。** 如果你熟悉並信任它的操作，可以開啟極速模式，不再每次詢問。（所有操作都支援撤回。）
*   **🎛️ Agent Dock。** 狀態列固定在輸入框上方，即使關閉側邊欄也能隨時看到目前進度。狀態、停止、審批等資訊一目瞭然。
*   **🔌 智慧防卡死。** 如果 Agent 開始陷入死迴圈或進展緩慢，引擎會自動中斷並通知你原因。如果執行時間過長，它也會主動詢問你的意見，不會在後台無休止地執行。

**💚 感謝所有早期購買 Powerpack 的用戶——此功能現在已為你免費解鎖。** 感謝大家一直以來的信任與支援。

## ✨ 更多功能優化

*   **⚡ Gemini Spark 整合：** 如果你的帳號已開啟 Google Spark，側邊欄會自動顯示 Spark 標籤頁。
*   **🎨 介面視覺煥新：** 整體介面進行了重新調優——間距更緊湊、對比度更舒適。同時加入了切換主題時的過渡動畫，希望帶來更好的視覺體驗。
*   **🎛️ 快捷設定入口：** 點擊瀏覽器工具列的擴充功能圖示即可直接打開設定面板，快速切換平台和功能開關。
*   **⌨️ AI Studio 支援 `/` 喚出：** 之前 `/` 喚出 Prompt 庫的功能僅限 Gemini 使用，現在 AI Studio 也可以使用了。
*   **💾 自動本機備份：** 擴充功能資料現在支援定時自動備份，你也可以隨時手動建立快照，提升資料安全性。
*   **📜 智慧滾動條增強：** 點擊 Smart Scrollbar 即可展開為訊息列表，方便長對話的瀏覽。
*   **📁 移動對話支援新建資料夾：** 在「移到資料夾」彈窗中新增了新建資料夾按鈕。

## 🐛 問題修復

*   **☁️ Google Drive 同步邏輯優化：** 改進了之前的自動合併邏輯。現在 Drive 不會再主動覆蓋或合併到你的本機資料中。如果需要恢復，必須由你手動發起下載。上傳仍然保持自動（如果已開啟同步）。這確保了本機資料始終是你最可靠的真實來源。
*   **🔍 修復 Gemini 掃描對話列表功能：** 修復了該功能偶發失效的問題。
*   **😴 修復長時間休眠導致斷連的問題：** 修復了分頁長時間閒置後側邊欄無回應的問題，現在可以正常重連。
*   **📐 修復頁面異常跳動問題：** 解決了 Gemini 介面偶爾出現的佈局抖動問題。
*   **⌨️ 修復重新命名時輸入空格退出的問題：** 現在修改名稱時輸入空格不會再意外退出編輯狀態。
*   **🕒 修復時間顯示錯誤：** 對話的建立時間和最後活躍時間顯示恢復正常。
*   **💎 新建 Gem/Notebook 實時檢測：** 建立新的 Gem 或 Notebook 後擴充功能能立即檢測到。
*   **⚪ 修復 Smart Scrollbar 灰色死點問題：** 解決了偶爾出現的無法點擊的圓點問題。
