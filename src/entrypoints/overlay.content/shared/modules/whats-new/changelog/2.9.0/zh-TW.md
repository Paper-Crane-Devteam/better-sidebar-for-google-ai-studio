# 🤖 v2.9.0 —— Agent 來了

還記得 2.8.0 我留的那句嗎？*「Agent 還在烤箱裡。」* 叮——烤好了。🔔

兩個半月，咖啡不知道灌了幾杯，引擎重寫好幾次（講出來都丟臉）。**AI Agent，正式上線。**

先講最核心的事：其他側邊欄套件給你的是按鈕——按一下做一件事。我這個給你的是一個**幫你幹活的人**。你講人話告訴它要什麼，它就真的去做——翻你的資料、自己判斷、一步步執行、做完回來報告。全程在你自己瀏覽器裡跑，用的是你自己的 Gemini 對話，不要 API key、不燒額外 token、資料不離開你的電腦。

## 🚀 主角：AI Agent

Gemini 輸入框裡打一個 `>`。

會跳出一個清單，你可以選一個**技能**，也可以不選直接讓 AI 自己判斷。然後像交代工作那樣跟它說你想幹嘛，剩下的看著就好。

**出廠就帶幾個技能讓你上手：**

*   **🗂️ 自動整理：** 「幫我把最近 200 個對話分到資料夾，順便打標籤。」它會看標題、自己想好分類、建資料夾、全搬進去。堆了半年沒管的爛攤子，一趟搞定。
*   **🔄 補全搜尋索引：** 你可能不知道——對話的內容只有你打開的時候才會被記下來。裝套件之前那些舊對話，資料庫裡只有個標題殼子、沒有內容，這就是全文搜尋老是搜不到東西的原因。這個技能把那些空殼找出來、把內容同步回來。跑完還是空的？代表 Google 那邊也沒了，就是個幽靈，讓 Agent 順手刪了就好。
*   **📊 拿你自己的資料當資料庫問：** 「上個月哪個資料夾裡的對話最多？」直接問，它查完告訴你。
*   **📝 批次管理 Prompt 和 Snippet：** 重寫、重新分類、去重、重新組織——把那堆亂的變成真正能用的東西。
*   **🛠️ 自己寫技能：** **設定 → Agent** 裡可以用你自己的指令定義技能。你講得清楚的重複流程，都能教給它，之後就是一張一鍵卡片。

### 🔓 別以為就只能幹這些

上面那些是**預設，不是天花板**。這點我必須講清楚，因為這才是重點。

Agent 底層能直接查套件的資料庫——對話、訊息、資料夾、標籤、Prompt、Snippet 全都能讀。它不是在五個固定動作裡挑，它自己寫 SQL 查你的資料、看結果、再決定下一步。所以真正的能力邊界是：**跟你資料有關的事，你講得清楚它就能做。**

怎麼探索上限？試試這些：

*   打 `>` 直接**問它**：「你到底能拿我的資料幹嘛？」「我這邊有什麼亂的是我自己沒注意到的？」讓它自己跟你推銷。
*   **把它當人聊，別當搜尋框用。** 支援多輪對話，上下文是連著的。「有意思，按月份拆開看看。」「加過星號的那些也來一遍。」「算了那兩個資料夾合併掉。」一輪接一輪推下去，它跟得上。
*   問那種我設計不出對應功能的事：「我哪些主題聊了又聊？」「三月那個 auth bug 的對話找出來歸到一起。」「我哪些 Prompt 從來沒用過？」「我上一季都在忙啥？」

老實說，最猛的玩法一定是我自己沒想到的。去折騰，然後回來跟我說。

**安全這塊，我覺得做得不錯：**

*   **🛑 你始終拍板。** 寫操作一律先問你，讀操作隨便跑。策略你自己定，也可以隨時改。
*   **⚡ 信得過就開極速模式。** 一個開關就不再問了。（有復原，放心。）
*   **🎛️ Agent Dock** 貼在輸入框上方，側邊欄關了也在。狀態、停止、審批，一眼全看到。不會再有「它到底還在跑嗎」的困惑。
*   **🔌 到處埋了斷路器。** 如果它開始重複、打轉、沒進展，引擎直接掐掉告訴你為什麼。跑太久沒人管的時候也會主動來問一下，不會在背景悶著頭硬磨。

**💚 當初用早鳥價買了 Powerpack 的朋友——這個功能現在免費到手了。** 它還不存在的時候你就掏錢了，感謝。去打個 `>`，看看你買到了什麼。

## ✨ 順帶還上了這些

*   **⚡ Gemini Spark 整合：** Google 有幫你開 Spark 的話，側邊欄會自動多一個 tab。不用設定，有就有。
*   **🎨 介面更清爽了：** 整體重新調過——間距更緊湊、對比度更舒服、主題重新打磨。看起來沒那麼吵了。還加了**切換主題時的過場動畫**，小細節但很舒服。
*   **🎛️ 點套件圖示開設定面板：** 工具列的圖示按一下就是控制面板，開關平台、開關功能，不用再翻選單。
*   **⌨️ AI Studio 也支援 `/` 了：** 之前 `/` 叫出 Prompt 庫只有 Gemini 能用，現在 AI Studio 也行了。
*   **💾 自動本機備份：** 套件資料定時自動備份，也可以隨時手動打快照。出事了能回滾，終於有後悔藥了。
*   **📜 Smart Scrollbar 能展開了：** 按一下展開成訊息列表，長對話終於能跳著看。
*   **📁 移動對話框裡能建資料夾了：** 「移到資料夾」彈窗裡加了**新增資料夾**按鈕。小事，但之前沒有真的很煩。

## 🐛 修了一堆，其中一個很重要

*   **☁️ Google Drive 同步不會再吃資料了。** 這條要認真講：之前的自動合併邏輯有時候會拿雲端蓋掉本機，很糟。**已經拿掉了。** 現在 Drive 永遠不會主動覆寫或合併進你的本機資料——要還原必須你自己手動發起下載。上傳還是自動的（有開同步的話）。本機資料就是唯一真相，句點。
*   **🔍 Gemini 掃描對話列表修好了。** 之前壞的，現在穩了。
*   **😴 不會再「人走了套件也走了」。** 分頁放著幾個小時回來發現側邊欄是死的——修了，現在能正常重連。
*   **📐 頁面不再莫名往上跳了。** 那個偶爾出現的 Gemini 版面抖動，沒了。
*   **⌨️ 空白鍵不會退出重新命名了。** 改名的時候按空白不再把你踢出去。
*   **🕒 時間顯示正常了。** 建立時間和最後活躍時間終於不亂寫了。
*   **💎 新建的 Gem / Notebook 馬上就能偵測到。** 不用再靠重整頁面了。
*   **⚪ 灰色死點沒了。** Smart Scrollbar 偶爾出現按不了的圓點，修了。
