# 🤖 v2.9.0 —— Agent 来了

还记得 2.8.0 我留的那句话吗？*「Agent 还在烤箱里。」* 叮——熟了。🔔

两个半月，咖啡不知道喝了多少杯，引擎重写了好几遍（说出来都丢人）。**AI Agent，正式上线。**

先把最核心的事儿说清楚：别的侧边栏插件给你的是按钮——你点一下它做一件事。我这个给你的是一个**干活的人**。你说人话告诉它要什么，它真的会去干——翻你的数据、自己判断、一步步执行、干完了回来汇报。全程都在你自己浏览器里跑，用的是你自己的 Gemini 会话，不要 API key，不烧额外 token，数据不出你的机器。

## 🚀 重头戏：AI Agent

Gemini 输入框里打一个 `>`。

弹出来一个列表，你可以选一个**技能**，也可以不选直接让 AI 自己判断。然后像交代工作一样跟它说你想干嘛，剩下的看着就行。

**出厂就带几个技能给你上手用：**

*   **🗂️ 自动整理：** "帮我把最近 200 个对话分到文件夹里，顺便打标签。" 它会看标题、自己想好分类、建文件夹、全搬进去。你攒了半年没整理的烂摊子，一趟搞定。
*   **🔄 补全搜索索引：** 你可能不知道——对话的消息内容只有你打开过的时候才会被记下来。装插件之前那些老对话，数据库里只有个标题壳子、没有内容，这就是全文搜索老搜不到东西的原因。这个技能把那些空壳对话找出来、把内容同步回来。跑完一轮还是空的？那说明 Google 那边也没了，就是个幽灵，让 Agent 顺手删了就行。
*   **📊 拿你自己的数据当数据库问：** "上个月哪个文件夹里的对话最多？" 直接问，它会查完告诉你。
*   **📝 批量管理 Prompt 和 Snippet：** 重写、重新归类、去重、重新组织——把那堆乱七八糟的变成真正能用的库。
*   **🛠️ 自己写技能：** **设置 → Agent** 里可以用你自己的指令定义技能。你能说清楚的重复流程，都能教给它，之后就是一张一键卡片。

### 🔓 别以为就只能干这些

上面那些是**预设，不是天花板**。这点我必须说清楚，因为这才是重点。

Agent 底层能直接查插件的数据库——对话、消息、文件夹、标签、Prompt、Snippet 全能读。它不是在五个固定动作里挑，它自己写 SQL 查你的数据、看结果、再决定下一步。所以真正的能力边界是：**跟你数据有关的事，你说得清楚它就能干。**

怎么探索上限？试试这些：

*   打 `>` 直接**问它**："你到底能拿我的数据干嘛？""我这里有什么乱的我自己没注意到？" 让它自己跟你推销。
*   **把它当人聊，别当搜索框用。** 它支持多轮对话，上下文是连着的。"有意思，按月份拆开看看。""标了星标的那些也来一遍。""算了那俩文件夹合并掉。" 一轮接一轮地推，它跟得上。
*   问那种我设计不出对应功能的事："我哪些话题聊了又聊？""三月那个 auth bug 的对话找出来归到一起。""我哪些 Prompt 从来没用过？""我上季度都在忙啥？"

说实话，最骚的玩法肯定是我自己没想到的。去折腾，然后回来告诉我。

**安全这块，我觉得做得不错：**

*   **🛑 你始终拍板。** 写操作一律先问你，读操作随便跑。策略你自己定，也可以随时改。
*   **⚡ 信得过就开极速模式。** 一个开关，不再问你了。（有撤回，放心。）
*   **🎛️ Agent Dock** 贴在输入框上方，侧边栏关了也在。状态、停止、审批，一眼全看到。不会再有「它到底还在跑吗」的疑问。
*   **🔌 到处埋了熔断器。** 要是它开始重复、打转、没进展，引擎直接掐掉告诉你为什么。跑太久没人管的时候它也会主动来问你一嘴，不会在后台闷头死磕。

**💚 当初早鸟价买了 Powerpack 的同学——这个功能现在免费到手了。** 它还不存在的时候你就掏钱了，谢谢。去打个 `>`，看看你买到了什么。

## ✨ 顺带还上了这些

*   **⚡ Gemini Spark 集成：** Google 给你开了 Spark 的话，侧边栏里会自动多出来一个 tab。不用配置，有就有。
*   **🎨 界面更清爽了：** 整体重新调了一遍——间距更紧凑、对比度更舒服、主题打磨过。看着没那么吵了。还加了**切换主题时的过渡动画**，小细节但很舒服。
*   **🎛️ 点插件图标开设置面板：** 浏览器工具栏的图标点一下就是控制面板，开关平台、开关功能，不用再翻菜单。
*   **⌨️ AI Studio 也支持 `/` 了：** 之前 `/` 唤出 Prompt 库只有 Gemini 能用，现在 AI Studio 也行了。
*   **💾 自动本地备份：** 插件数据定时自动备份，你也可以随时手动打快照。出事了能回滚。终于有后悔药了。
*   **📜 Smart Scrollbar 能展开了：** 点一下展开成消息列表，长对话终于能跳着看。
*   **📁 移动对话框里能建文件夹了：** 「移到文件夹」弹窗里加了**新建文件夹**按钮。小事，但之前没有是真的烦。

## 🐛 修了一堆，其中一个很重要

*   **☁️ Google Drive 同步不会再吃数据了。** 这条我要认真说：之前的自动合并逻辑有时候会用云端覆盖本地，这很糟糕。**已经干掉了。** 现在 Drive 永远不会主动覆盖或合并到你的本地数据里——要恢复必须你手动发起下载。上传还是自动的（如果你开了同步的话）。本地数据就是唯一真相，句号。
*   **🔍 Gemini 扫描对话列表修好了。** 之前不工作，现在稳了。
*   **😴 不会再「人走了插件也走了」。** 标签页放着几个小时回来发现侧边栏是死的——修了，现在能正常重连。
*   **📐 页面不再莫名往上跳了。** 那个间歇性的 Gemini 布局抽搐，没了。
*   **⌨️ 空格不会退出重命名了。** 改名时打空格不再把你踢出编辑态。
*   **🕒 时间显示正常了。** 创建时间和最后活跃时间终于不瞎编了。
*   **💎 新建的 Gem / Notebook 立刻能检测到。** 不用再靠刷新页面这套仪式了。
*   **⚪ 灰色死点没了。** Smart Scrollbar 偶尔出现的点不动的圆点，修了。
