# 🤖 v2.9.0 —— AI Agent 正式上线

经过一段时间的开发与底层架构调整，我们为大家带来了一个全新的功能：**AI Agent**。🎉

我们希望为你提供一个更实用的**智能助手**，而不仅仅是几个快捷按钮。你可以用自然语言告诉它你的需求，它会尝试主动检索你的数据、进行分析判断、分步骤执行，并在完成后向你汇报。所有这一切都在你的浏览器本地运行，使用的是你当前的 Gemini 会话，不需要 API key，不消耗额外 token，数据也绝对不会离开你的设备，确保隐私安全。

## 🚀 核心更新：AI Agent

在 Gemini 输入框中输入 `>` 即可唤出。

此时会弹出一个列表，你可以选择一个**预设技能**，或者不选，直接用自然语言描述你的需求，让 AI 自己判断如何执行。

**我们准备了以下基础技能供大家体验：**

*   **🗂️ 自动整理：** “帮我把最近 200 个对话分类到文件夹中，并打上标签。” 它会自动分析对话标题、尝试进行分类、创建文件夹，并完成移动，协助你整理积压的对话记录。
*   **🔄 补全搜索索引：** 你可能注意到，全文搜索有时找不到一些早期的对话内容。这是因为在安装插件前的旧对话，数据库中默认只有标题。这个技能可以帮你找出这些“空壳”对话，并自动同步内容。如果同步后依然为空，说明云端也已失效，Agent 会协助你清理这些无效数据。
*   **📊 数据查询：** “上个月哪个文件夹里的对话最多？” 直接提问，它会查询本地数据并给出答案。
*   **📝 批量管理 Prompt 和 Snippet：** 协助重写、重新分类、去重或重新组织，帮助整理你的素材库。
*   **🛠️ 自定义技能：** 在**设置 → Agent** 中，你可以用自己的指令来定义新技能。如果你有重复性的工作流程，可以尝试教给它，之后只需一键即可运行。

### 🔓 探索更多可能

除了预设技能，Agent 底层支持直接查询插件的数据库，包括对话、消息、文件夹、标签、Prompt 和 Snippet 等。它能够根据你的需求自动编写查询语句，分析结果，并决定下一步操作。只要是与你本地数据相关的操作，只要能清晰描述，都可以尝试让它去完成。

你可以尝试以下使用方式：

*   输入 `>` 直接**问它**：“你能用我的数据做些什么？” 或 “我的数据里有哪些需要整理的地方？” 听听它的建议。
*   **把它当成助手进行多轮对话。** 它支持上下文连贯。例如：“很有意思，请按月份再拆分看看。” “把标了星标的对话也按这个规则处理一下。” “算了，把那两个文件夹合并吧。” 
*   尝试一些我们没有预设的功能：“我经常聊哪些话题？” “把三月份关于 auth bug 的对话找出来整理到一起。” “我有哪些 Prompt 从没使用过？” 
*   如果你发现了有趣的用法，欢迎随时分享给我们。

**在安全性与可控性方面：**

*   **🛑 你来决定。** 默认情况下，所有修改数据的操作都会先询问你的确认，读取操作则可以直接执行。你可以随时在设置中调整策略。
*   **⚡ 极速模式。** 如果你熟悉并信任它的操作，可以开启极速模式，不再每次询问。（所有操作都支持撤回。）
*   **🎛️ Agent Dock。** 状态栏固定在输入框上方，即使关闭侧边栏也能随时看到当前进度。状态、停止、审批等信息一目了然。
*   **🔌 智能防卡死。** 如果 Agent 开始陷入死循环或进展缓慢，引擎会自动中断并通知你原因。如果运行时间过长，它也会主动询问你的意见，不会在后台无休止地运行。

**💚 感谢所有早期购买 Powerpack 的用户——此功能现在已为你免费解锁。** 感谢大家一直以来的信任与支持。

## ✨ 更多功能优化

*   **⚡ Gemini Spark 集成：** 如果你的账号已开启 Google Spark，侧边栏会自动显示 Spark 标签页。
*   **🎨 界面视觉焕新：** 整体界面进行了重新调优——间距更紧凑、对比度更舒适。同时加入了切换主题时的过渡动画，希望带来更好的视觉体验。
*   **🎛️ 快捷设置入口：** 点击浏览器工具栏的插件图标即可直接打开设置面板，快速切换平台和功能开关。
*   **⌨️ AI Studio 支持 `/` 唤出：** 之前 `/` 唤出 Prompt 库的功能仅限 Gemini 使用，现在 AI Studio 也可以使用了。
*   **💾 自动本地备份：** 插件数据现在支持定时自动备份，你也可以随时手动创建快照，提升数据安全性。
*   **📜 智能滚动条增强：** 点击 Smart Scrollbar 即可展开为消息列表，方便长对话的浏览。
*   **📁 移动对话支持新建文件夹：** 在「移到文件夹」弹窗中新增了新建文件夹按钮。

## 🐛 问题修复

*   **☁️ Google Drive 同步逻辑优化：** 改进了之前的自动合并逻辑。现在 Drive 不会再主动覆盖或合并到你的本地数据中。如果需要恢复，必须由你手动发起下载。上传仍然保持自动（如果已开启同步）。这确保了本地数据始终是你最可靠的真实来源。
*   **🔍 修复 Gemini 扫描对话列表功能：** 修复了该功能偶发失效的问题。
*   **😴 修复长时间休眠导致断连的问题：** 修复了标签页长时间闲置后侧边栏无响应的问题，现在可以正常重连。
*   **📐 修复页面异常跳动问题：** 解决了 Gemini 界面偶尔出现的布局抖动问题。
*   **⌨️ 修复重命名时输入空格退出的问题：** 现在修改名称时输入空格不会再意外退出编辑状态。
*   **🕒 修复时间显示错误：** 对话的创建时间和最后活跃时间显示恢复正常。
*   **💎 新建 Gem/Notebook 实时检测：** 创建新的 Gem 或 Notebook 后插件能立即检测到。
*   **⚪ 修复 Smart Scrollbar 灰色死点问题：** 解决了偶尔出现的无法点击的圆点问题。
