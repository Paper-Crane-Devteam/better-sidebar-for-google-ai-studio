# 🔧 v2.9.2 — 資料夾選單與穩定性優化

一次小型維護更新，集中在易用性改進與問題修復。

## ✨ 改進

*   **📁 資料夾下拉選單新增 Gem Chat 和 Notebook Chat：** 資料夾的下拉選單中新增了快捷操作，可以直接在該資料夾內新建 Gem 對話或 Notebook 對話。
*   **🤖 Agent 穩定性與可讀性優化：** 提升了 Agent 的整體運行穩定性，並優化了任務執行日誌的可讀性，更方便查看執行過程。

## 🐛 問題修復

*   **📂 修復 Gem Chat 和 Notebook Chat 的資料夾歸入邏輯：** 修復了 Gem 對話和 Notebook 對話無法正確落入其指定資料夾的問題。
*   **🔄 修復掃描對話列表不顯示載入動畫：** 修復了掃描對話列表時未顯示 loading 指示器的問題。
