# 🔧 v2.9.2 — Folder Menus & Stability Improvements

A small maintenance release focused on usability tweaks and bug fixes.

## ✨ Improvements

*   **📁 New Gem Chat & Notebook Chat in Folder Dropdown:** The folder dropdown menu now includes quick actions to start a new Gem chat or Notebook chat directly within that folder.
*   **🤖 Agent Stability & Readability:** Improved the overall stability of the Agent and made task execution logs easier to read and follow.

## 🐛 Bug Fixes

*   **📂 Fixed Gem Chat & Notebook Chat Folder Assignment:** Fixed an issue where Gem chats and Notebook chats were not correctly placed into their assigned folders.
*   **🔄 Fixed Scan Chat List Loading Indicator:** Fixed an issue where the loading spinner was not displayed while scanning the chat list.
