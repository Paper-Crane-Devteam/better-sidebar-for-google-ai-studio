# 🔧 v2.9.2 — Menús de carpeta y mejoras de estabilidad

Una pequeña versión de mantenimiento centrada en ajustes de usabilidad y correcciones de errores.

## ✨ Mejoras

*   **📁 Nuevo Gem Chat y Notebook Chat en el menú desplegable de carpetas:** El menú desplegable de la carpeta ahora incluye acciones rápidas para iniciar un nuevo Gem chat o Notebook chat directamente dentro de esa carpeta.
*   **🤖 Estabilidad y legibilidad del Agent:** Se mejoró la estabilidad general del Agent y se hicieron los registros de ejecución de tareas más fáciles de leer y seguir.

## 🐛 Correcciones de errores

*   **📂 Corrección de asignación de carpeta para Gem Chat y Notebook Chat:** Se solucionó un problema donde los Gem chats y Notebook chats no se ubicaban correctamente en sus carpetas asignadas.
*   **🔄 Corrección del indicador de carga al escanear la lista de chats:** Se solucionó un problema donde el indicador de carga no se mostraba al escanear la lista de chats.
