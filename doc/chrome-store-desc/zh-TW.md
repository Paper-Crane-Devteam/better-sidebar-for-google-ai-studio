Gemini & AI Studio 一站式對話管理工具：資料夾整理、全文搜尋、對話匯出、AI Agent 自動化、提示詞庫、Google Drive 雲端同步、主題美化。
在一個套件中輕鬆管理 AI 對話的收藏、歸檔、搜尋和備份。現在，你還可以嘗試讓 AI 助手為你分擔一些整理工作。

BETTER SIDEBAR FOR GEMINI & AI STUDIO 希望能成為你得力的助手，為你提升工作效率。我們努力將原本簡單的列表結構轉化為一個更有條理的知識庫，讓你的 AI 工作流更加順暢。

🔥 最新更新 (v2.9.0)

🤖 AI Agent（全新嘗試）：
• 我們加入了一個實驗性的 AI Agent 功能。在 Gemini 輸入框輸入 ">" 並描述你的需求，它會嘗試理解並幫你執行多步驟操作。
• 內建技能：包含自動整理對話到資料夾、補全搜尋索引、查詢資料、批次管理 Prompt 和 Snippet 等功能。
• 支援自訂：你可以在「設定 → Agent」中編寫適合自己工作流的專屬技能。
• 靈活對話：支援多輪對話，Agent 會盡可能保持上下文連貫，幫你一步步完成任務。
• 安全機制：我們注重你的資料安全。所有的寫操作都需要你的確認（也提供免確認的極速模式供信任的場景使用）。內建斷路機制以防止死迴圈。
• 隨時喚起：無論側邊欄是否開啟，Agent Dock 都會安靜地浮在輸入框上方，隨時待命。
• 感謝支持：作為感謝，早期購買 Powerpack 的用戶將自動解鎖該功能。

⚡ Gemini Spark 支援：
• 針對已取得 Spark 權限的 Google 帳號，側邊欄會自動顯示 Spark 標籤頁，希望能為你省去設定的麻煩。

🎨 介面與互動最佳化：
• 重新調整了介面的間距與對比度，並優化了主題細節。切換主題時，現在會有平滑的過場動畫，希望能帶來更舒適的視覺體驗。

🎛️ 快捷控制面板：
• 點擊瀏覽器工具列的套件圖示，可以直接喚出控制面板，方便你快速開關平台和功能，無需進入深層選單。

⌨️ AI Studio 支援 "/" 捷徑指令：
• 備受期待的 "/" 呼出 Prompt 庫捷徑鍵，現在也可以在 AI Studio 中使用了。

💾 自動本機備份：
• 新增了定時自動備份功能，你也可以隨時手動建立快照。如果不小心誤操作，可以透過快照輕鬆還原資料。

📜 智慧捲軸最佳化：
• 點擊捲軸現在可以展開完整的訊息列表，方便你在長對話中快速定位。

📁 資料夾移動體驗最佳化：
• 在「移到資料夾」彈窗中增加了「新增資料夾」按鈕，讓你在整理時更順手。

🐛 細節修復：
• 調整了 Google Drive 同步邏輯，現在僅作為備份，不再自動覆寫本機資料（還原需手動下載），以保護你的本機資料安全。
• 修復了部分情況下 Gemini 掃描對話列表異常、休眠後側邊欄卡死、頁面版面閃爍等問題。感謝大家的耐心回饋，幫助我們不斷完善。

🚀 核心功能

🤖 AI AGENT（新功能）

在輸入框中輸入 ">" 即可喚起 Agent。用日常語言描述你的需求，它會盡力幫你執行整理、查詢資料等任務。支援自訂技能、多輪對話、審批機制、極速模式、斷路保護。側邊欄關了也能透過 Agent Dock 操控。

📂 側邊欄與整理

📂 資料夾與自訂顏色
建立多層資料夾分類對話，拖拽即可整理。支援自訂資料夾和標籤顏色。

🔍 搜尋與篩選
全文檢索所有歷史訊息。支援按標題、標籤、類型等多條件組合篩選。可限定「在目前對話中搜尋」。

🏷️ 智慧標籤
為對話加上自訂標籤，直接在標題處顯示，支援即時篩選。

⭐ 收藏與置頂
將最常用的 Prompt 或重要對話置頂，隨時快速存取。

📊 時間軸檢視
透過「今天」、「昨天」、「上週」分組瀏覽你的工作軌跡。

🗑️ 批次刪除
批次刪除對話時同步修改 Google 端資料，徹底告別幽靈對話。

📥 對話匯出
將單一對話匯出為 Markdown、純文字或 JSON。批次匯出需 Powerpack。

✂️ Snippets 精華摘錄
從 AI 回覆中擷取精華，存入專屬 Snippet 庫，支援資料夾管理。

👀 對話大綱
開啟大綱檢視，一覽長對話的結構脈絡。

📝 對話備註與富提示
為對話加上說明；懸停即可查看建立日期、標籤和備註。

💾 自動本機備份
套件資料定時自動備份，支援手動快照和回滾到之前狀態。

🔒 隱私優先承諾

• 完全本機化：使用瀏覽器內建 SQLite 資料庫儲存你的資料夾結構。
• 無雲端同步：你的資料夾、標籤和備註不會傳送到我們的伺服器。
• 無資料訓練：絕不使用你的對話內容訓練 AI 模型。
• Agent 本機執行：AI Agent 使用你自己的 Gemini 工作階段，不需 API key，不消耗額外 token，資料不離開你的電腦。
