🚀 核心功能

🤖 AI AGENT（新功能）

輸入框打 ">" 召喚 Agent。用白話描述任務，它自動執行——自動整理、查詢資料、管理 Prompt、同步遺漏訊息等。支援自訂技能、多輪對話、審批機制、極速模式、斷路保護。側邊欄關了也能透過 Agent Dock 操控。

📂 側邊欄與整理

📂 資料夾與自訂顏色
建立多層資料夾分類對話，拖拽即可整理。支援自訂資料夾和標籤顏色。

🔍 搜尋與篩選
全文檢索所有歷史訊息。支援按標題、標籤、類型等多條件組合篩選。可限定「在目前對話中搜尋」。

🏷️ 智慧標籤
為對話加上自訂標籤，直接在標題處顯示，支援即時篩選。

⭐ 收藏與置頂
將最常用的 Prompt 或重要對話置頂，隨時快速存取。

📊 時間軸檢視
透過「今天」、「昨天」、「上週」分組瀏覽你的工作軌跡。

🗑️ 批次刪除
批次刪除對話時同步修改 Google 端資料，徹底告別幽靈對話。

📥 對話匯出
將單一對話匯出為 Markdown、純文字或 JSON。批次匯出需 Powerpack。

✂️ Snippets 精華摘錄
從 AI 回覆中擷取精華，存入專屬 Snippet 庫，支援資料夾管理。

👀 對話大綱
開啟大綱檢視，一覽長對話的結構脈絡。

📝 對話備註與富提示
為對話加上說明；懸停即可查看建立日期、標籤和備註。

💾 自動本機備份
套件資料定時自動備份，支援手動快照和回滾到之前狀態。

🔒 隱私優先承諾

• 完全本機化：使用瀏覽器內建 SQLite 資料庫儲存你的資料夾結構。
• 無雲端同步：你的資料夾、標籤和備註不會傳送到我們的伺服器。
• 無資料訓練：絕不使用你的對話內容訓練 AI 模型。
• Agent 本機執行：AI Agent 使用你自己的 Gemini 工作階段，不需 API key，不消耗額外 token，資料不離開你的電腦。
