Универсальный органайзер чатов, менеджер промптов и набор инструментов для Google Gemini и AI Studio.
Организуйте разговоры по папкам, ищите по всем сообщениям, экспортируйте чаты, синхронизируйте с Google Drive — и теперь позвольте AI-агенту управлять вашими данными.

BETTER SIDEBAR FOR GEMINI & AI STUDIO — максимальный ускоритель рабочего процесса для разработчиков, промпт-инженеров и продвинутых пользователей ИИ.

Мы превращаем стандартный интерфейс в мощную организованную базу знаний. Хватит бесконечно листать историю — начните работать эффективно.

🔥 НОВОЕ (v2.9.0)

🤖 AI Agent — главное:
• Наберите «>» в поле ввода Gemini и опишите задачу. ИИ читает ваши данные, принимает решения, выполняет многошаговую работу и отчитывается.
• Встроенные навыки: автосортировка чатов по папкам, заполнение поискового индекса (синхронизация сообщений старых чатов), запросы к данным как к БД, массовое управление промптами и сниппетами.
• Создавайте свои навыки в Настройки → Agent.
• Не ограничен пресетами — Agent запрашивает всю базу данных и делает всё, что вы можете описать.
• Многораундовый диалог: углубляйтесь раунд за раундом, контекст сохраняется.
• Безопасность: запись требует одобрения, чтение свободно. Режим скорости. Предохранители убивают зацикленные прогоны.
• Agent Dock висит над полем ввода, даже при закрытом сайдбаре.
• Покупатели Powerpack Early Bird получают Agent бесплатно.

⚡ Интеграция Gemini Spark:
• Если Spark доступен на вашем аккаунте, появляется как нативная вкладка автоматически.

🎨 Более чистый UI и анимации тем:
• Плотнее отступы, лучше контраст, доработанные темы. Плавный анимированный переход при смене темы.

🎛️ Панель настроек в иконке расширения:
• Клик по иконке в панели инструментов открывает панель управления. Без меню.

⌨️ Slash-команды в AI Studio:
• Шорткат «/» для библиотеки промптов теперь работает и в AI Studio.

💾 Автоматический локальный бэкап:
• Данные бэкапятся по расписанию. Ручные снэпшоты. Откат доступен.

📜 Smart Scrollbar раскрывается:
• Клик для раскрытия в полный список сообщений.

📁 Создание папки в диалоге перемещения:
• В диалоге «Переместить в папку» есть кнопка «Новая папка».

🐛 Важные исправления:
• Google Drive больше не перезаписывает локальные данные — восстановление только ручным скачиванием.
• Исправлены сканирование чатов Gemini, зомби-сайдбар после сна вкладки, скачок вёрстки, пробел отменяет переименование, неверные метки времени, обнаружение Gem/Notebook, мёртвые точки скроллбара.

🚀 ОСНОВНЫЕ ФУНКЦИИ

🤖 AI AGENT (НОВОЕ)

Наберите «>» для вызова Агента. Опишите задачу на естественном языке — он выполнит: автосортировка, запросы к данным, управление промптами, синхронизация недостающих сообщений. Пользовательские навыки, многораундовый диалог, одобрение записи, режим скорости, предохранители. Работает через Agent Dock даже при закрытом сайдбаре.

🔒 КОНФИДЕНЦИАЛЬНОСТЬ ПРЕЖДЕ ВСЕГО

• 100% локально: встроенная SQLite база данных в браузере.
• Без отправки на наши серверы: папки, теги и заметки НЕ уходят к нам.
• Без обучения: мы не читаем ваши разговоры для тренировки ИИ.
• Agent работает локально: используется ваша собственная сессия Gemini. Без API-ключей, без лишних токенов, данные не покидают машину.
