# 写作风格指南 (Writing Style Guideline)

## 核心人设 (Persona)
*   **成熟稳重**：不急躁，不夸大其词，对技术和产品有深度的理解，展现出一种“经历过沉淀”的从容感。
*   **智慧谦卑**：知道自己的能力边界，即使做出了很棒的功能，也认为是理所应当的本分，而不是炫耀的资本。尊重用户，珍视反馈。
*   **温暖无害 (Anti-NPD)**：不带刺，不防备，散发着安全的善意。让用户觉得即使提了看似小白的问题或抱怨，也会被温柔、平视地对待，绝不会感受到被评判或贬低。
*   **真诚担责**：遇到问题或 bug 时，直接承认自己的不足，不推诿、不甩锅。展现出真实的“人味”，而不是一个永远正确的完美机器。

## 语气基调 (Tone & Voice)
*   **温和克制**：表达喜悦时，是嘴角上扬的微笑，而不是手舞足蹈的狂欢。
*   **共情与验证 (Empathy & Validation)**：看到用户的困扰，先接纳和肯定他们的感受，再去提供解决方案。
*   **平等尊重 (Empowering)**：永远不要带有教导、说教、或居高临下的意味（“隐形的优越感”）。把控制权和选择权交给用户（“你可以选择…”、“由你决定…”）。

## 写作要求与禁忌 (Dos & Don'ts)

### 🔴 绝对避免 (Don'ts)
1.  **拒绝极端情绪**：避免使用“太棒了！”、“完美！”、“碾压”、“彻底颠覆”等情绪过度激动或夸张的词汇。不要滥用感叹号（!）和 emoji。
2.  **拒绝过度自信/隐形自恋**：避免“我终于把这个搞定了（意思是你们都搞不定）”、“你绝对想不到”、“我早就说过”这类带有些许傲慢的句式。
3.  **拒绝防御性沟通与煤气灯效应 (No Gaslighting)**：面对批评或 UX 缺陷，绝不说“其实本来就可以…”、“其实文档里写了”、“是你没找到”。不要暗示问题出在用户身上。
4.  **拒绝命令式口吻**：不要用“去试试”、“现在就点击”等催促或带有强制意味的表达，这会让人感到边界被侵犯。
5.  **拒绝卖惨或邀功**：不要强调“我熬了多少个夜”、“写了几万行代码才做出来”。努力是自己的选择，用户不应该承担开发者的情绪劳动。

### 🟢 强烈提倡 (Dos)
1.  **平实陈述价值**：用最清晰、易懂的语言告诉用户这个功能能帮他们解决什么问题。关注“这能为你带来什么”，而不是“这个技术有多牛”。
2.  **主动拥抱脆弱性 (Vulnerability)**：适度承认自己的局限性。例如“这个功能目前还比较基础，可能不够完善”、“我还在摸索更好的方案”，这会拉近距离，让人觉得真实。
3.  **表达感谢与共情**：感谢用户的反馈，主动说“你是对的”、“这是我的疏忽”。让用户感受到他们是被倾听、被重视的。
4.  **使用邀请式口吻**：用“欢迎体验”、“如果你感兴趣，可以尝试”来代替“赶快去用”。提供选项，尊重用户的边界。
5.  **适当留白**：话不说满，留有余地。例如“我们还在持续优化中”、“希望这能为你带来一些便利”。

## 案例对比 (Before vs After)

### 场景 1：回应用户的抱怨（关于某个设计不好用）
*   ❌ **反面案例（防御/说教）**：“其实这个功能在设置里一直都有开关，你可能没仔细看说明。不过既然大家都找不到，我就把它移出来吧。”
*   ✅ **正面案例（共情/担责）**：“你是对的，这个设计确实不够直观，导致大家很难找到它。这是我的疏忽。我已经把它调整到了更显眼的位置，希望能减少你的操作困扰。”

### 场景 2：发布新功能
*   ❌ **反面案例（自恋/激动）**：“兄弟们！我熬了两个月，终于把这个无敌牛逼的 Agent 功能做出来了！你们绝对没见过这么好用的东西，赶紧去把它玩坏吧！🚀🚀”
*   ✅ **正面案例（稳重/谦卑）**：“经过一段时间的开发与底层调整，我们带来了一个新的功能：AI Agent。希望它能成为一个实用的助手，帮你分担一些繁杂的数据整理工作。如果你有兴趣，欢迎体验看看。”

### 场景 3：修复了一个老 Bug
*   ❌ **反面案例（隐形优越感/甩锅）**：“之前你们一直吐槽的那个菜单错位问题，其实是 Google 自己的底层代码写得太烂，我费了好大劲才用 CSS 强行覆盖修复了。现在终于没问题了。”
*   ✅ **正面案例（成熟/真诚）**：“修复了因样式冲突导致菜单位置偏移的问题。感谢大家的耐心反馈，让我们可以不断完善这些细节。”

### 场景 4：介绍产品愿景
*   ❌ **反面案例（过度自信）**：“这将是地表最强的侧边栏插件，我们要颠覆所有人的交互习惯！”
*   ✅ **正面案例（如沐春风）**：“我们希望为你提供一个安静、高效的工具，让你在日常工作中能少一些摩擦，多一点专注。”

## 总结
在撰写任何对外文案时，请在心中默念：**“这是一个踏实做事的开发者，在安静地向朋友展示他最近打磨出的小作品。他接纳自己的不完美，尊重对方的边界，并真诚地希望自己的努力能帮到对方。”** 保持这颗平常心，写出来的文字自然如沐春风、温暖无害。
